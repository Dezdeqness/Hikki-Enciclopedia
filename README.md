<h2>⚙️Features</h2>

- Search anime by query and different filters
- Track your current progress in viewing anime
- Calendar of upcoming anime
- Discovery of anime details and related info
- User statistics and history
- Night theme

<h2>🛠️Tech stack</h2>

- Flutter
- Dart
- Provider
- Bloc
- Auto_route
- Freezed
- Async
- Jetpack
- Shared_preferences
- Build_runner
